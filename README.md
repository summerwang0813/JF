# OJO Figma AI Workbench

一个 OJO-like 的 AI 组件画布原型，用于验证“Figma 组件库 -> AI 可调用组件 -> 无限画板搭建页面”的工作流。

## 文件入口

- `outputs/ojo-workbench.html`: 主工作台页面
- `outputs/ojo-design-system.css`: OJO 风格设计规范与组件样式
- `outputs/ojo-component-library.js`: 可被页面调用的组件库
- `outputs/ojo-visual-spec.md`: OJO 视觉规范沉淀
- `outputs/heading-component-demo.html`: 旧入口，自动跳转到主工作台

## 本地预览

直接用浏览器打开：

```text
outputs/ojo-workbench.html
```
