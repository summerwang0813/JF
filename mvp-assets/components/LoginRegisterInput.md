# LoginRegisterInput 登录注册输入框

## 来源

- Figma 文件：方德 App 组件库（26 版）
- Figma Node：`28777:4260`
- 组件名称：`登录注册输入框`
- 组件属性：`Type`

## 组件定位

用于登录注册链路的基础表单组件。Agent 在生成登录、注册、验证码、密码登录、找回密码等流程时，应优先调用该组件，不应重新手写输入框样式。

## 可调用变体

| Type | 使用场景 |
|---|---|
| 文本-默认 | 邮箱、账号等普通文本输入初始态 |
| 文本-输入中 | 普通文本输入聚焦或已有输入 |
| 电话-默认 | 手机号输入初始态 |
| 电话-输入中 | 手机号输入聚焦或已有输入 |
| 密码-默认 | 密码输入初始态 |
| 密码-输入中闭眼 | 密码输入中，密文展示 |
| 密码-输入中睁眼 | 密码输入中，明文展示 |
| 验证码 | 4 位短信验证码输入 |
| 验证码错误 | 验证码校验失败 |

## 暂不开放变体

## 交互规则

- 输入框聚焦时，从默认态切换到对应“输入中”态。
- 输入框失焦且内容为空时，回到默认态。
- 文本、手机号、密码输入中展示清除按钮。
- 密码输入支持闭眼/睁眼切换。
- 手机号输入展示 `+86` 区号、下拉箭头和分隔线。
- 验证码固定为 4 位数字。
- 验证码错误时，4 个格子边框变红，并展示错误提示。
- 重新发送按钮可由业务控制是否禁用。

## 视觉规则

- 基准宽度：`343px`
- 输入框高度：`56px`
- 输入框内边距：`16px`
- 默认边框：`#E5E8EB`
- 聚焦边框：`#0068FF`
- 错误边框：`#F5444F`
- 输入文字：`16px / 24px`
- 验证码格子：`60px * 60px`，圆角 `8px`
