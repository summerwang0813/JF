# 登录注册输入框交互说明

## 目标

让 Agent 能根据 PRD 自动生成登录注册相关页面，并在左侧输出交互说明、中间生成可操作 Demo、右侧生成高保真页面。

## 基础状态

1. 用户进入登录页，手机号输入框展示 `电话-默认`。
2. 用户点击手机号输入框，状态切换为 `电话-输入中`。
3. 用户输入 11 位手机号后，页面上的“获取验证码”按钮可从禁用态切换为可点击态。
4. 用户点击“获取验证码”，进入验证码页。
5. 验证码页展示 `验证码` 组件，支持 4 位数字输入。
6. 校验失败时切换为 `验证码错误`，展示错误文案和重新发送入口。

## Agent 生成规则

- 识别到“手机号登录、短信登录、注册、验证码”时，应调用 `LoginRegisterInput`。
- 不允许在页面中重新手写输入框样式。
- 左侧交互说明应拆成用户动作、组件状态、页面反馈三层。
- 中间 Demo 需要可输入手机号，并能演示按钮禁用/可用变化。
- 右侧高保真页面应展示关键状态，包括默认、输入中、验证码、错误态。
