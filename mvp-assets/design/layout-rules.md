# 登录注册页面布局规则

## 基准

- 移动端基准画板：`375px * 812px`
- 页面左右安全边距：`24px`
- 内容宽度：`327px`
- 输入框组件宽度：`343px`，在页面内容区可按容器宽度收敛到 `100%`

## 登录注册页面

- 页面背景默认白色。
- 页面标题使用 `24px / 34px / 600`。
- 表单区建议从顶部 `120px` 后开始排布。
- 输入框之间垂直间距使用 `16px` 或 `20px`。
- 主按钮高度使用 `40px`。
- 协议文案使用 `12px / 18px`。

## 验证码页面

- 验证码组件位于标题下方。
- 4 个验证码格子横向均分，单个尺寸 `60px * 60px`。
- 错误文案出现在验证码格子下方左侧。
- 重新发送出现在同一行右侧。

## Demo 交互要求

- 手机预览必须可操作。
- 未输入合法手机号时，“获取验证码”按钮禁用。
- 输入合法手机号后，“获取验证码”按钮可点击。
- 点击后进入验证码页。
